## مسار توزيع التاسكات (ملخص)

1. **محمد / مها** → مشروع → خطة شهرية → إنشاء/توليد مهام وتعيينها
2. **نيرة** → مهام الكتابة
3. **يوسف / مريم** → مهام التصميم
4. **نفين** → مهام الفيديو
5. **ألاء** → متابعة + نشر المعتمد على السوشيال
